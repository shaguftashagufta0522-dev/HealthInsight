# HealthInsight – Healthcare Analytics & Predictive Insights

HealthInsight is a data analytics and business intelligence dashboard built using Python, Flask, SQLite, and JavaScript.

The project analyzes synthetic healthcare data to identify patient trends, hospital operations, diagnosis patterns, treatment costs, and readmission insights.

## 📊 Dashboard Features

- Healthcare KPI dashboard
- Patient demographic analysis
- Department-wise hospital visits
- Diagnosis analysis
- Insurance and admission analysis
- Treatment cost analysis
- Date and category filters
- CSV data upload and validation
- Data quality monitoring
- Readmission risk demonstration
- 3-month visit forecasting
- Analytical summary report
- CSV export

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- SQL
- JavaScript
- Chart.js
- HTML
- CSS
- pandas / NumPy concepts
- Data Visualization
- Data Analysis

## 📈 Key Analytics

The dashboard provides:

- Total Patients
- Average Patient Age
- Average Length of Stay
- Total Hospital Visits
- Readmission Rate
- Average Treatment Cost

## 🔍 Data Analysis

The application supports analysis based on:

- Gender
- Age Group
- Department
- Diagnosis
- Insurance Type
- Admission Type
- Admission Date

## 🔮 Predictive Analytics

HealthInsight includes demonstration-level predictive features for:

- Readmission risk
- Short-term hospital visit forecasting

These features are intended for analytics and educational purposes and do not provide medical diagnosis or treatment advice.
